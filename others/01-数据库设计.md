# 数据库设计文档

## 概述

本文档定义了多模态科学文献智能解析平台的所有数据库表结构，包括 MySQL 关系型数据库和 Neo4j 图数据库的设计。

## 一、MySQL 数据库设计

### 1. 用户与权限模块

#### 1.1 users（用户表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 用户唯一标识 (UUID) |
| username | VARCHAR(50) | UNIQUE, NOT NULL | 用户名 |
| email | VARCHAR(255) | UNIQUE, NOT NULL | 邮箱 |
| password_hash | VARCHAR(255) | NOT NULL | 密码哈希 |
| full_name | VARCHAR(100) | | 真实姓名 |
| avatar_url | VARCHAR(500) | | 头像 URL |
| role | VARCHAR(20) | NOT NULL, DEFAULT 'user' | 角色：admin/annotator/reviewer/user |
| is_active | TINYINT(1) | NOT NULL, DEFAULT 1 | 是否激活 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |
| last_login | DATETIME | | 最后登录时间 |

```sql
CREATE TABLE users (
    id VARCHAR(36) PRIMARY KEY DEFAULT (UUID()),
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    full_name VARCHAR(100),
    avatar_url VARCHAR(500),
    role VARCHAR(20) NOT NULL DEFAULT 'user',
    is_active TINYINT(1) NOT NULL DEFAULT 1,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    last_login DATETIME

CREATE INDEX idx_users_is_active ON users(is_active);
```

#### 1.2 roles（角色表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 角色 ID |
| name | VARCHAR(50) | UNIQUE, NOT NULL | 角色名称 |
| description | TEXT | | 角色描述 |
| permissions | JSON | NOT NULL | 权限列表 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |

```sql
CREATE TABLE roles (
    id VARCHAR(36) PRIMARY KEY DEFAULT (UUID()),
    name VARCHAR(50) UNIQUE NOT NULL,
    description TEXT,
    permissions JSON NOT NULL DEFAULT (JSON_ARRAY()),
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- 预设角色权限
INSERT INTO roles (name, description, permissions) VALUES
('admin', '系统管理员', JSON_ARRAY('all')),
('reviewer', '审核员', JSON_ARRAY('document:read', 'document:write', 'annotation:read', 'annotation:review', 'task:read', 'task:write')),
('annotator', '标注员', JSON_ARRAY('document:read', 'annotation:read', 'annotation:write', 'task:read')),
('user', '普通用户', JSON_ARRAY('document:read', 'task:read'));
```

**权限码体系**：`permissions` 数组存放 `resource:action` 格式的权限码，用于 RBAC 细粒度权限控制，分三级：

| 级别 | 权限码 | 说明 |
|------|--------|------|
| 文档级 | `document:read` / `document:write` | 查看 / 上传、编辑、删除、解析文档（配合上传者归属校验） |
| 任务级 | `task:read` / `task:write` | 查看 / 创建、分配、操作任务（配合负责人/创建人归属校验） |
| 标注级 | `annotation:read` / `annotation:write` / `annotation:review` | 查看 / 创建编辑 / 审核标注 |
| 系统级 | `system:user:manage` / `system:role:manage` / `system:audit:read` | 用户管理 / 角色权限管理 / 查看操作日志 |

`admin` 角色用 `all` 通配符（后端 `has_permission` 亦对 `role == admin` 直接放行）。

### 2. 文档管理模块

#### 2.1 documents（文档表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 文档 ID |
| title | VARCHAR(500) | NOT NULL | 文档标题 |
| doi | VARCHAR(100) | UNIQUE | DOI 标识 |
| authors | JSON | | 作者列表 |
| abstract | TEXT | | 摘要 |
| keywords | JSON | | 关键词列表 |
| publication_date | DATE | | 发表日期 |
| journal | VARCHAR(200) | | 期刊名称 |
| references | JSON | | 参考文献结构化条目列表（CSL-JSON 风格，含作者/标题/期刊/年份/卷/期/页码/DOI/类型） |
| file_path | VARCHAR(500) | NOT NULL | 文件存储路径 |
| file_size | BIGINT | | 文件大小（字节） |
| page_count | INTEGER | | 页数 |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'uploaded' | 状态：uploaded/parsing/parsed/failed |
| uploaded_by | VARCHAR(36) | FK → users.id, NOT NULL | 上传用户 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

```sql
CREATE TABLE documents (
    id VARCHAR(36) PRIMARY KEY DEFAULT (UUID()),
    title VARCHAR(500) NOT NULL,
    doi VARCHAR(100) UNIQUE,
    authors JSON DEFAULT (JSON_ARRAY()),
    abstract TEXT,
    keywords JSON DEFAULT (JSON_ARRAY()),
    publication_date DATE,
    journal VARCHAR(200),
    references JSON DEFAULT (JSON_ARRAY()),
    file_path VARCHAR(500) NOT NULL,
    file_size BIGINT,
    page_count INTEGER,
    status VARCHAR(20) NOT NULL DEFAULT 'uploaded',
    uploaded_by VARCHAR(36) NOT NULL,
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (uploaded_by) REFERENCES users(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE INDEX idx_documents_status ON documents(status);
CREATE INDEX idx_documents_uploaded_by ON documents(uploaded_by);
CREATE INDEX idx_documents_publication_date ON documents(publication_date);
CREATE FULLTEXT INDEX idx_documents_title ON documents(title);
```

### 3. 任务管理模块

#### 3.1 tasks（任务表）

| 字段名 | 类型 | 约束 | 说明 |
|--------|------|------|------|
| id | VARCHAR(36) | PRIMARY KEY | 任务 ID |
| task_type | VARCHAR(30) | NOT NULL | 类型：parsing/extraction/graph（自动化）/ parse_validation/entity_annotation/graph_review（人工分配） |
| document_id | VARCHAR(36) | FK → documents.id | 关联文档 |
| assigned_to | VARCHAR(36) | FK → users.id | 分配给用户（负责人） |
| assigned_by | VARCHAR(36) | FK → users.id | 分配人 |
| due_at | DATETIME | | 截止日期 |
| status | VARCHAR(20) | NOT NULL, DEFAULT 'pending' | pending/running/completed/failed/cancelled |
| priority | INTEGER | NOT NULL, DEFAULT 0 | 优先级（0-10） |
| progress | FLOAT | NOT NULL, DEFAULT 0 | 进度（0-100） |
| params | JSON | | 任务参数 |
| result | JSON | | 任务结果 |
| error_message | TEXT | | 错误信息 |
| celery_task_id | VARCHAR(255) | | Celery 任务 ID |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| started_at | DATETIME | | 开始时间 |
| completed_at | DATETIME | | 完成时间 |

```sql
CREATE TABLE tasks (
    id VARCHAR(36) PRIMARY KEY DEFAULT (UUID()),
    task_type VARCHAR(30) NOT NULL,
    document_id VARCHAR(36),
    assigned_to VARCHAR(36),
    assigned_by VARCHAR(36),
    due_at DATETIME,
    status VARCHAR(20) NOT NULL DEFAULT 'pending',
    priority INTEGER NOT NULL DEFAULT 0,
    progress FLOAT NOT NULL DEFAULT 0,
    params JSON DEFAULT (JSON_OBJECT()),
    result JSON DEFAULT (JSON_OBJECT()),
    error_message TEXT,
    celery_task_id VARCHAR(255),
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    started_at DATETIME,
    completed_at DATETIME,
    FOREIGN KEY (document_id) REFERENCES documents(id),
    FOREIGN KEY (assigned_to) REFERENCES users(id),
    FOREIGN KEY (assigned_by) REFERENCES users(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE INDEX idx_tasks_status ON tasks(status);
CREATE INDEX idx_tasks_assigned_to ON tasks(assigned_to);
CREATE INDEX idx_tasks_document_id ON tasks(document_id);
CREATE INDEX idx_tasks_created_at ON tasks(created_at);
```

CREATE TABLE annotations (

    FOREIGN KEY (element_id) REFERENCES document_elements(id),
    FOREIGN KEY (annotated_by) REFERENCES users(id),
    FOREIGN KEY (first_reviewed_by) REFERENCES users(id),

# alembic/env.py
from app.core.config import settings
from app.models.base import Base

target_metadata = Base.metadata

def run_migrations_online():
    connectable = create_engine(settings.DATABASE_URL)
    with connectable.connect() as connection:
        context.configure(
            connection=connection,
            target_metadata=target_metadata,
            compare_type=True
        )
        with context.begin_transaction():

## 五、性能优化建议

### 1. MySQL 优化

- **连接池**：使用 SQLAlchemy 内置连接池或 ProxySQL
- **分区表**：对 operation_logs 等大表按时间分区
- **查询优化**：使用 EXPLAIN 分析查询计划
- **定期 OPTIMIZE**：保持表健康状态

### 2. Neo4j 优化

- **批量导入**：使用 neo4j-admin import 进行初始数据导入
- **查询优化**：使用 PROFILE 分析查询计划
- **内存配置**：调整 page_cache 和 heap 大小

### 3. Redis 优化

- **内存淘汰策略**：配置 maxmemory-policy allkeys-lru
- **持久化**：启用 AOF + RDB 混合持久化
- **集群模式**：数据量大时启用 Redis Cluster
