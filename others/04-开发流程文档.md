#### 2.1.3 环境初始化脚本

```bash
#!/bin/bash
# scripts/setup.sh

echo "开始环境初始化..."

# 创建虚拟环境
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cd ..

# 安装前端依赖
cd frontend
pnpm install
cd ..

# 启动基础服务
docker-compose -f docker/docker-compose.dev.yml up -d mysql redis neo4j minio

# 等待服务启动
sleep 10

# 初始化数据库
cd backend
alembic upgrade head
python scripts/init_db.py
cd ..

echo "环境初始化完成！"
```

### 2.4 CI/CD 流程

#### 2.4.1 GitHub Actions - CI

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [main, develop]
  pull_request:
    branches: [main]

jobs:
  backend-test:
    runs-on: ubuntu-latest
    services:
      mysql:
        image: mysql:8.0
        env:
          MYSQL_ROOT_PASSWORD: 20020522
        options: >-
          --health-cmd "mysqladmin ping"
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5
      redis:
        image: redis:7
        options: >-
          --health-cmd "redis-cli ping"
          --health-interval 10s
          --health-timeout 5s
          --health-retries 5

    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.11"

      - name: Install dependencies
        run: |
          cd backend
          pip install -r requirements.txt
          pip install pytest pytest-asyncio pytest-cov

      - name: Run linters
        run: |
          cd backend
          pip install ruff mypy
          ruff check app/
          mypy app/

      - name: Run tests
        run: |
          cd backend
          pytest --cov=app --cov-report=xml

      - name: Upload coverage
        uses: codecov/codecov-action@v3

  frontend-test:
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Setup Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 20

      - name: Install pnpm
        uses: pnpm/action-setup@v2

      - name: Install dependencies
        run: |
          cd frontend
          pnpm install

      - name: Type check
        run: |
          cd frontend
          pnpm type-check

      - name: Lint
        run: |
          cd frontend
          pnpm lint

      - name: Build
        run: |
          cd frontend
          pnpm build
```

#### 2.4.2 GitHub Actions - CD

```yaml
# .github/workflows/cd.yml
name: CD

on:
  push:
    tags:
      - "v*"

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Build and push Docker images
        run: |
          docker build -t backend:${{ github.ref_name }} ./backend
          docker build -t frontend:${{ github.ref_name }} ./frontend
          # Push to registry...

      - name: Deploy to production
        run: |
          # SSH to server and deploy
          ssh ${{ secrets.DEPLOY_HOST }} "cd /app && docker-compose pull && docker-compose up -d"
```

## 三、Phase 2: 核心功能开发

### 3.1 开发顺序

```
1. 数据库模型定义
   └── 创建所有 SQLAlchemy 模型

2. Pydantic Schemas
   └── 定义所有请求/响应模型

3. 认证系统
   ├── JWT 生成和验证
   ├── 登录/注册 API
   ├── 密码加密
   └── 权限中间件

4. 文档管理
   ├── 文件上传
   ├── 文件存储 (MinIO)
   ├── 文档 CRUD
   └── 文档列表/搜索

5. PDF 解析服务
   ├── PyMuPDF 集成
   ├── PDFPlumber 集成
   ├── 图像提取
   └── 解析结果存储

6. 异步任务
   ├── Celery 配置
   ├── 解析任务
   ├── 任务状态追踪
   └── 任务 API

7. 前端页面
   ├── 登录页
   ├── 文档列表页
   ├── 文档详情页
   └── 布局组件
```

### 3.2 每日开发流程

```
Morning:
  1. 拉取最新代码
  2. 查看任务板，确认今日任务
  3. 创建功能分支: git checkout -b feature/xxx

Development:
  1. 编写代码
  2. 编写测试
  3. 本地运行验证

End of Day:
  1. 提交代码: git commit -m "feat: xxx"
  2. 推送到远程: git push origin feature/xxx
  3. 创建 Pull Request
  4. 更新任务状态
```

### 3.3 代码审查流程

```
1. 开发者创建 PR
2. 自动触发 CI 检查
3. 至少 1 名 reviewer 审查
4. 审查通过后合并到 develop
5. 定期合并到 main
```

### 6.2 测试示例

```python
# tests/unit/test_document_service.py
import pytest
from app.services.document_service import DocumentService
from unittest.mock import AsyncMock, patch

@pytest.mark.asyncio
async def test_upload_document():
    service = DocumentService()
    
    mock_file = AsyncMock()
    mock_file.filename = "test.pdf"
    mock_file.content_type = "application/pdf"
    mock_file.read.return_value = b"fake pdf content"
    
    with patch.object(service.minio_client, 'upload_file') as mock_upload:
        result = await service.upload_document(mock_file, "Test Doc", "user-1")
        
        assert result.title == "Test Doc"
        assert result.status == "uploaded"
        mock_upload.assert_called_once()

@pytest.mark.asyncio
async def test_upload_invalid_file():
    service = DocumentService()
    
    mock_file = AsyncMock()
    mock_file.content_type = "image/png"
    
    with pytest.raises(ValueError, match="Only PDF files"):
        await service.upload_document(mock_file, None, "user-1")
```

```yaml
version: "3.8"

services:
  backend:
    image: scientific-doc-backend:latest
    deploy:
      replicas: 2

        limits:
          memory: 2G

      - DEBUG=false
      - LOG_LEVEL=WARNING

    image: scientific-doc-frontend:latest
    deploy:
      replicas: 2
    restart: unless-stopped

  mysql:
    image: mysql:8.0
    environment:
      - MYSQL_ROOT_PASSWORD=20020522
      - MYSQL_DATABASE=wx
    volumes:
      - mysql_data:/var/lib/mysql
    restart: unless-stopped

  redis:
    image: redis:7
    command: redis-server --requirepass ${REDIS_PASSWORD}
    restart: unless-stopped

  neo4j:
    image: neo4j:5
    environment:
      - NEO4J_AUTH=neo4j/${NEO4J_PASSWORD}
    restart: unless-stopped

    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
      - ./ssl:/etc/nginx/ssl
    restart: unless-stopped
```

```
main          - 生产环境
  ├── develop   - 开发环境
  │   ├── feature/xxx    - 功能分支
```

### 8.2 提交信息规范

```
feat:     新功能
fix:      修复 bug

test:     测试
chore:    构建/工具

示例:
feat: add document upload endpoint
fix: resolve PDF parsing timeout issue
docs: update API documentation

```
