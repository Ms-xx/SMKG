# 10.2 缺失功能明细（六方向）实现计划

## Context（背景与目标）

`XiangMu.md` 第十章「10.2 缺失功能明细」列出了对标外部赛项六大命题模块的
15 个子项（此前全部标注 ❌/未立项）。用户要求本轮「完成 10.2」，约定：
- 交付范围：**全部六个方向（一）~（六）**
- 前端深度：**高价值功能配前端页面**，其余仅后端 API
- 无法实际进行的部分（真实网络下载、真实翻译、真实 LLM 生成、真实 GraphRAG 接入等）：**跳过并在文档中详述降级方式**

沿用项目既有工程约定——**零依赖、可插拔、可降级**；AI/检索类模块用 `Depends(get_current_user)`；
纯 Python 服务 + 全局单例；性能/降级测试用 `monkeypatch` 模拟缺失依赖。

已确认可复用的现成能力：
- 参考文献结构化：`backend/app/services/reference_service.py`（`references` 为 `List[dict]`，
  每条含 `index/authors/title/journal/year/volume/issue/pages/doi/type/raw`；另有 `references_to_csl_json`/`references_to_bibtex`）
- GraphRAG 问答代理：`backend/app/services/graphrag_integration.py`（`rag_query(question, return_context)` → `{question, answer, keywords, context?}`）
- 前端模板：`frontend/src/api/modules.ts`（API 函数）、`src/types/index.ts`、`src/router/index.tsx` + `Sidebar.tsx`（路由+菜单）、
  `src/pages/KnowledgeGraph/MultiAgentPage.tsx`、`DocumentDetailPage.tsx`（参考文献 `List` 渲染位置）
- 测试夹具：`test/conftest.py`（`client`/`token`/`db`/`API_PREFIX`）

## 六个方向交付清单

### （一）语义去重与版本管理【P2】
- 新增 `backend/app/services/deduplication_service.py`：
  - `simhash(text)`、`chunk_fingerprints(chunks)`（纯 Python n-gram + 哈希，零依赖；numpy 缺失自动降级）
  - `extract_arxiv_version(title)`（正则识别 v1↔v7）
  - `find_duplicates(documents)`（分组相似文档，输出 cluster/similarity/suggestion）
  - `extract_affiliations(text)`（机构信息正则启发式抽取）
- 新增 `backend/app/api/v1/deduplication.py`：`POST /deduplication/detect`、`POST /deduplication/affiliations`
- `config.py` 新增 `DEDUPLICATION_ENABLED`、`DEDUP_THRESHOLD`
- 测试 `test/test_deduplication_service.py`
- **跳过并文档化**：`Document.authors` 结构化入库（需 `ALTER TABLE` 迁移，风险见项目记忆；仅提供抽取函数，不迁移 schema）

### （二）抗幻觉溯源与多文对比【P1】
- 新增 `backend/app/services/source_anchor_service.py`：
  - `extract_anchors(context_chunks)` → 从带 `document_id/page_number/snippet` 的分块生成溯源锚点列表
  - `multi_document_compare(chunks_by_doc, question)` → 跨文档聚合候选分块按主题/时间线分组（关键词打分排序；无 LLM 降级为规则模板结论）
- 新增 `backend/app/api/v1/source_anchor.py`：`POST /source-anchor/anchors`、`POST /source-anchor/compare`
- 测试 `test/test_source_anchor_service.py`
- **跳过并文档化**：与 GraphRAGTest `/query` 的真实接入（需 8001 服务返回带来源元数据的 context）；真实 LLM 对比结论降级为模板

### （三）版式联动阅读 + 双向翻译【P1】
- 新增 `backend/app/services/citation_link_service.py`：
  - `extract_inline_citations(text)`（正则定位正文 `[n]`/`[1,2]`/`(Author, Year)`）
  - `build_citation_map(pages_text, references)`（引用 ↔ 参考文献 index 双向映射锚点）
  - `extract_title_tree(pdf_path)`（PyMuPDF `get_toc()` 标题树，缺层降级版面标题推断）
- 新增 `backend/app/api/v1/citation_link.py`：`POST /citation-link/map`、`POST /citation-link/title-tree`
- 测试 `test/test_citation_link_service.py`（纯函数，构造 `pages_text` 不依赖真实 PDF）
- **前端**：`DocumentDetailPage.tsx` 参考文献列表加锚点 id + 正文引用双向跳转；标题树导航组件
- **跳过并文档化**：中英对比阅读 + 划词/整篇翻译（依赖翻译模型/API）

### （四）论文检索追踪与推荐【P2】
- 新增 `backend/app/services/paper_retrieval_service.py`：
  - `search_arxiv(query, max_results)`、`search_pubmed(query, max_results)`（stdlib `urllib` + `xml.etree` 解析 Atom/E-utilities，零额外依赖）
  - `recommend(local_refs, candidates)`（关键词/Jaccard/年份相关性打分 + 推荐理由）
  - 网络失败降级返回空列表 + `error` 标记
- 新增 `backend/app/api/v1/paper_retrieval.py`：`POST /paper-retrieval/search`、`POST /paper-retrieval/recommend`
- `config.py` 新增 `PAPER_RETRIEVAL_ENABLED`、`ARXIV_MAX_RESULTS`
- 测试 `test/test_paper_retrieval_service.py`（mock 网络，不真实请求）
- **前端**：论文检索 + 推荐页（查询表单 + 结果表格）
- **跳过并文档化**：真实 PDF 下载入库、定时追踪（sickle/feed）

### （五）引用图谱挖掘 + 综述【P1】
- 新增 `backend/app/services/citation_graph_service.py`：
  - `build_citation_network(references)`（按 title/doi 匹配建节点 + CITES 边，纯 Python）
  - `page_rank(graph)`、`betweenness_centrality(graph)`（自实现零依赖，numpy 可选加速）
  - `generate_survey(references, top_papers)`（规则模板综述：主题聚合 + 时间线）
  - `deduplicate_future_work(chunks)`（simhash/minhash 聚合去重）
- 新增 `backend/app/api/v1/citation_graph.py`：`POST /citation-graph/network`、`/key-papers`、`/survey`
- 测试 `test/test_citation_graph_service.py`
- **前端**：引用图谱可视化页（复用 ForceGraph）+ 基石节点高亮 + 综述输出
- **跳过并文档化**：真实 LLM 综述生成（降级规则模板）

### （六）写作辅助 + 可视化 Copilot【P2】
- 新增 `backend/app/services/writing_assistant_service.py`：
  - `generate_outline(idea, references)`（论文框架模板；**无幻觉**：References 只用真实传入条目，不编造）
  - `generate_diagram_script(diagram_type, spec)`（TikZ/Graphviz/Mermaid/Matplotlib 脚本字符串模板）
  - `csv_to_chart(csv_text, chart_type)`（纯 Python 解析 CSV + 生成零依赖 SVG：折线/柱状/雷达/表格）、`figure_caption(chart_meta)`
- 新增 `backend/app/api/v1/writing_assistant.py`：`POST /writing-assistant/outline`、`/diagram`、`/csv-chart`
- 测试 `test/test_writing_assistant_service.py`
- **前端**：写作辅助页（框架生成 + 图表脚本 + CSV→图表预览）
- **跳过并文档化**：中英学术翻译（翻译模型）；真实 LLM 生成（降级模板）
