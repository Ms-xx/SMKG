当前文档详情页 [DocumentDetailPage.tsx](file:///d:\work\VSCodeWork\LX\frontend\src\pages\Documents\DocumentDetailPage.tsx) 已能在**摘要**内建立 `[n]`↔参考文献 `ref-{index}` 的双向跳转，并展示标题树，但**正文全文**未加载，`/citation-link/map` 的能力（正文引用定位 + 按引用反查正文位置）未接入前端，中英对照与翻译也未落地。本步骤补齐：

## 一、后端

### 1.1 `DocumentService.get_fulltext`
[document_service.py](file:///d:\work\VSCodeWork\LX\backend\app\services\document_service.py) 新增方法（放在 `get_page_elements` 附近），复用既有 `get_document` 做归属/权限校验：

### 1.3 前端 API
[modules.ts](file:///d:\work\VSCodeWork\LX\frontend\src\api\modules.ts) `documentApi` 下新增：
- `getFullText(documentId)` → `api.get('/documents/${documentId}/fulltext')`，返回 `{document_id, page_count, pages:[{page_number,text}]}`。

## 二、前端 `DocumentDetailPage.tsx`

主改动集中在[文档详情页](file:///d:\work\VSCodeWork\LX\frontend\src\pages\Documents\DocumentDetailPage.tsx)。为可测性，把正文渲染抽成子组件（同文件内或单独文件 `FullTextBody`），其余状态挂在本页组件。

### 2.1 状态与加载
- 新增 `fulltext {pages}[]`、`citationMap {citations, by_reference}`、`bilingual:boolean`、`translations Record<page_number,string>`、`translateLoading`、`selPopover`（划词翻译）。
- `useEffect`：当 `doc.status==='parsed'` 且有 `id` 时：
  1. `documentApi.getFullText(id)` → 存 `fulltext.pages`；
  2. `citationLinkApi.map(pages_text, doc.references)` → 存 `citationMap`，用于正文 `[n]` 定位与参考文献反查正文。

### 2.2 正文全文 + 双向跳转（5.1）
- 在 `titleTree` 之后渲染可折叠 `Card`「正文」（仅 `doc.status==='parsed'`）。
- 正文渲染：按页分块，每页标题 `第 {n} 页`；对每页文本，依据 `citationMap.citations`（按 page_index+start 排序）切分字符串，把 `[n]` 数字渲染为链接，anchor id 形如 `body-cite-{pageNumber}-{start}`，点击 `scrollToId('ref-{n}')`。
- 参考文献条目：把现有「回到正文」从「仅摘要命中」扩展为正文命中也有效——若 `citationMap.by_reference[idx]` 存在，点击 `scrollToId('body-cite-{page}-{start}')` 并短暂高亮该引用（`highlight` className）。
- author_year 引用（ref_index=None）在正文中按原样保留文本，不做跳转。

### 2.3 中英对照 + 同步滚动（5.2）
- 正文卡片头部放「中英对照」开关（AntD `Segmented`/`Switch`）。
- 开启后：每页 `writingAssistantApi.translate(text, 'zh')` 并行翻译，结果缓存 `translations[pageNumber]`（展示 `backend` 以便知悉降级）。
- 双栏布局（flex 两列滚动容器，原文 / 译文），监听滚动事件按高度比例同步另一侧 `scrollTop`（`onScroll` + ref）。
- 译文缺失/加载中显示占位。

### 2.4 划词翻译 + 整篇翻译（5.3）
- **划词翻译**：正文字段监听 `onMouseUp`/`onSelectionChange`，检测到非空选区时在本页正文区显示「翻译选中文本」小操作；点击调 `writingAssistantApi.translate(selection)`，用 AntD `Tooltip`/`Popover` 展示译文。
- **整篇翻译**：正文头部「整篇翻译」按钮，对所有页 `translate`（与 2.3 共用 `translations` 缓存逻辑），完成后自动打开中英对照视图；公式/代码保留英文依赖 `/translate` 现有提示词（尽力而为）。
